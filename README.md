# 🚀 Modern Developer Portfolio

A professional, responsive portfolio website built with React and featuring modern glassmorphism design. Perfect for showcasing your development skills and projects with an integrated admin dashboard for easy content management.

## ✨ Features

- **Modern Glassmorphism Design** - Sleek, professional appearance
- **Admin Dashboard** - Easy content management via URL access
- **Project Images Support** - Showcase your work with beautiful visuals  
- **Firebase Integration** - Cloud data sync with localStorage fallback
- **Fully Responsive** - Perfect on all devices
- **Professional Contact Form** - Direct client communication
- **SEO Optimized** - Ready for search engines

## 🛠️ Tech Stack

- **React 19** - Modern React with hooks
- **Vite** - Lightning-fast build tool
- **Firebase** - Cloud database and authentication
- **CSS3** - Custom properties and glassmorphism effects
- **Netlify** - Production deployment

## 📦 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/Ekazahro/protofolio.git
cd protofolio
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Open `http://localhost:5174`

## 🎯 Admin Dashboard

### Access Admin Panel
- Navigate to: `http://localhost:5174/#admin`
- Login: `admin` / `admin123`

### Admin Features
- **Projects Management** - Add/edit projects with images
- **Skills Management** - Update technical skills
- **About Section** - Customize personal story
- **Messages Viewer** - Check contact form submissions
- **Firebase Migration** - Sync data to cloud

## 🌐 Deployment

### Netlify Deployment
1. Build for production:
```bash
npm run build
```

2. Deploy to Netlify:
- Connect GitHub repository
- Build command: `npm run build`
- Publish directory: `dist`

### Environment Variables (Optional)
For Firebase integration, add to Netlify:
```
VITE_FIREBASE_API_KEY=your-api-key
VITE_FIREBASE_PROJECT_ID=your-project-id
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
```
